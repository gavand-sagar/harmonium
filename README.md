# Sur Catcher

Play your harmonium and see every note live as sargam (with Devanagari) and Western notation, with a tuning meter, a 3-octave keyboard view, optional chord detection, a copyable transcript, tap-to-catch with tempo-aware playback, and a live mode where a harmonium follows your singing.

Single static `index.html`, no build step. Audio stays in the browser.

Live at https://harmonium.sagar-gavand.co.in. Deployed on Vercel; every push to `main` deploys automatically.
