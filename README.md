# Sur Catcher

Play your harmonium and see every note live as sargam (with Devanagari) and Western notation, with a tuning meter, a 3-octave keyboard view, optional chord detection and a copyable transcript.

Single static `index.html`, no build step. Audio stays in the browser.

Live at https://harmonium.sagar-gavand.co.in. Deployed on Vercel; every push to `main` deploys automatically.
